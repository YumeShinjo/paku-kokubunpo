| `wakare-tango-11` | 「兄は毎晩数学を勉強する。」を単語で区切る | 答えは「勉強する」を1語(複合動詞)とする。教科書によっては、「勉強」(名詞)+「する」(動詞)と、2語に分ける扱いもある。アプリの他の単元(「受験する」「出場する」を、サ変の複合動詞とする)とは、そろっている。 | 「勉強する」を使わず、「走る」「読む」のように、1語でよい動詞に差し替える。 |
| `kaji-doushi-katsuyokei-14` | 「一緒に運動___う。」(「する」の未然形) | 答えは「しよ」(「しよ+う」)。学校文法では、「しよう」を、未然形「し」+助動詞「よう」と分ける扱いが一般的。「う」と「よう」の使い分け(五段は「う」、一段・サ変は「よう」)に合わない可能性がある。 | 「運動___ない」(答え「し」)にする。ただし、解説にある「し・せ・さ」の3つの未然形の説明と、合わせて直す。 |
| `kizuna-shushoku-05` | 「彼は昨日買った本を読んだ。」で、「昨日」が直接修飾する語 | 答えは「買った」。ただし、「昨日、読んだ」とも読めるので、かかり先が2通りになる。 | 「昨日買った」と読むしかない文(例: 「昨日買った本は面白い」)にする。 |
| `kizuna-shushoku-07` | 「遠くから響く音楽が聞こえる。」で、「遠くから」が直接修飾する語 | 答えは「響く」。ただし、「遠くから聞こえる」とも読める。 | 「遠くから響く音楽」の「聞こえる」を、別の述語にして、かかり先を1つにする。 |
| `miwake-magirawashii-04` | 「明日は晴れるらしい。」の「らしい」(解説) | 解説の「人から聞いた情報をもとに推定している(伝聞・推定)」の「伝聞」は、学校文法の「らしい」(推定)にない。 | 解説を「根拠にもとづいて推量している(推定)」にする。 |
| `hashi-kaku-07` | 「彼は九時___学校を出た。」(答え「から」) | 「出る」は一瞬の動作で、「九時に」の方が自然。「から」でも文法は合うが、少し不自然。 | 「彼は九時___学校で勉強した。」のように、続く動作にする。 |
| `ohza-shikibetsu-05` / `ohza-shikibetsu-09` | 「ご覧になられました」「お帰りになられました」を、「誤り(二重敬語)」とする | 多くの教科書・参考書では二重敬語は誤りとする。ただし、文化庁「敬語の指針」では、「お(ご)〜になられる」を、習慣として定着した言い方として、必ずしも誤りとしない見方もある(本文は、確かめられていない)。 | 「おっしゃられる」「召し上がられる」(02・07)だけを残し、05・09は、「二重敬語」の説明に注意を添える。 |
