# 14. 出典・ライセンス・プライバシー

素材の出典の管理とアプリ内の表示、ソースコードと素材のライセンス、プライバシーポリシー(アプリが実際に扱う情報)を定める。素材の置き場所は13・12章、保存キーは10章、サーバーのデータは9章。

> **個人名・アカウント名・メールアドレス・URLの具体値は、この章に書かない**(公開リポジトリのため)。制作者名・運営者名・お問い合わせ先は、それぞれの元のファイルを参照する。素材の作者は、サイトやサービスの名前までにとどめる。

### クレジット画面の表示のしかた(`buildCreditGroups`)

ネタバレを避けるため、曲名・効果音名・ファイル名・使用箇所は出さない。

| 種別 | 行の作り方 |
|---|---|
| BGM・SE | 「作曲者名 - サイト名」の並び(台帳の出典が「サイト名 / 作曲者名」ならその順に直す)。同じ出典は1つにまとめる。**規約が決まった書式を求める出典は、その書式に置きかえ、サイトへのリンクにする** |
| 画像 | 生成AIによる画像は、制作方法の1文に1つにまとめて「イラスト: …」。それ以外は「素材名: 出典」 |
| フォント | 「名前(ライセンス)」 |
| ライブラリ・生成AIモデル・制作素材 | クレジット画面には出さず、「くわしい出典」にだけ出す |

規約が、書式つきの表記を必須としている出典(コードに書式がある): ポケットサウンド、OtoLogic(CC BY 4.0。改変したことを添える)、PeriTune(CC BY 4.0)、On-Jin(二次配布・無断利用の禁止の表記つき)。

クレジット画面の「使用しているオープンソースソフトウェア」は7つ: React(MIT)、Vite / vite-plugin-pwa(MIT)、Zustand(MIT)、Firebase JS SDK(Apache 2.0)、lucide-react(ISC)、qrcode-generator(MIT)、jsQR(Apache 2.0)。

## 14.4 プライバシー

文章の正本は `docs/PRIVACY_POLICY.md`(制定日 2026-09-30。運営者名はそのファイルを参照)。アプリが実際に扱う情報を、コードから確認した結果を示す。

| ポリシーの記述 | コードでの確認 |
|---|---|
| 名前・メールアドレス・電話番号・住所を集めない | 入力欄はニックネームとクラスコード(ランキング)、お問い合わせフォーム(外部のGoogleフォーム)だけ(9章)。**一致** |
| 広告・アクセス解析・トラッキングを使わない。Cookie を使わない | コードに、広告・解析のライブラリや呼び出しはない。Cookie を設定する処理もない(`package.json`、`src`)。Firebase 側(コンソール)の設定は**未確認**(ポリシーの運営者向けメモにも「コードからは確認できなかった」とある) |
| 端末に保存する情報の一覧(進捗、得点、既読、星、記録、成長、ガイドの既読、アイコン、ランキング設定、途中経過、設定、お知らせの既読、匿名認証、キャッシュ、退避コピー) | 10章の保存キー13個と一致する。言の葉の森の記録、正解した問題の記録も入っている。**一致** |
| サーバーに保存する情報: ランキング(ニックネーム、アイコン、得点、更新時刻)、累計正解数、匿名認証 | 9章の `classes/.../members/{uid}`・`players/{uid}`・匿名認証と一致。**一致** |
| 引き継ぎコードには、ニックネームと匿名IDを含まない | 10章のとおり、含まない。**一致** |
| カメラは QR の読み取りだけに使い、保存も送信もしない | `TransferRestoreScreen.tsx`・`qr.ts`。映像を送信・保存する処理はない。**一致** |
| 本アプリ本体は、Firebase(Hosting・Authentication・Cloud Firestore)以外の外部サービスと通信しない。お問い合わせフォームは別のサービス | ソースの外部URLは、お問い合わせフォームと、クレジットの出典のリンク(押したときだけ開く外部リンク)。フォントと音声は自前で配信。**一致** |
| 「データを初期化」で、端末の情報と、(通信できれば)ランキングの記録を消す。サーバーの累計正解数と匿名IDは消えない | 10章のとおり。**一致** |
| 中学生を含む未成年者を想定。クラスコードは推測されにくいものに。ニックネームに個人を特定する名前を入れない | ランキングの入力画面に同じ注意書きがある(9章)。**一致** |
| お問い合わせの内容は、対応が完了してから1年以内に削除 | 運用の約束(コードからは確認できない) |

- 「法的な確認は受けていない下書きである」旨は、ポリシーの運営者向けメモ(公開されない節)にある。
- 公開前の運営者向けメモには、「アプリ側の変更(別途)」として、ランキング画面の注意書き、ポリシーの表示画面の追加が挙がっているが、**どちらも実装済み**(9章、`PrivacyPolicyScreen.tsx`)。
