> **この章はネタバレを含む。**

### 成長

| 項目 | 内容 |
|---|---|
| 成長段階(`growthStage`) | エリアをクリアするたびに、`エリアの順 + 1` へ進める(減らない)。序章=1、ことばの市場=2、…、王座の間=8 |
| アクセサリー | `growthStage − 1` 個(0〜7個)を、順に重ねる。ことばの市場のクリアで1つ目、王座の間のクリアで7つ目 |
| 通知 | エリアクリアのたびに、通知「コトが せいちょうしたよ!」(びっくりの表情・成長の効果音)を、マップに戻ってから出す(序章のクリアでも出るが、アクセサリーは増えない) |
| 増える条件 | **エリアクリアのときだけ**。星(苦手問題)の克服では増えない |
| アクセサリーの中身 | データ上は、番号(1〜7)の画像だけ。何が増えるかは画像次第。コトのメモの文には「ポーチに腕輪、スカーフにブローチ……」とある。`homeLines.ts` のコメントには、腕輪・ブローチ・耳のリボン・モノクルなどがある |
| 保存 | `growthStage` だけを端末に保存(`mascotStore`)。旧版が保存していた克服ボーナスは、次の保存から消える |

### 表情

表情の種類(`MASCOT_EXPRESSIONS`)は7つ: `happy`(喜び)、`sad`(しょんぼり)、`eating`(もぐもぐ)、`surprised`(びっくり)、`sleepy`(眠そう)、`combo`(コンボ中)、`hungry`(苦手問題への意欲)。ほかに、最初の画面だけ手を振る絵 `wave`(表情の素材名ではなく、星がないときの専用のポーズ)。素材(`mascot/<表情>`)がなければ、通常の絵のまま。

| 場面 | 表情 |
|---|---|
| 正解のポップアップ | 喜び。星を克服したときはもぐもぐ。5連続以上のコンボ中はコンボ |
| 不正解のポップアップ | しょんぼり。仕分けで1回目に外し2回目で合ったときは、喜び |
| ボス戦の負けの画面 | しょんぼり(大) |
| ステージのクリア画面 | 喜び。エリアクリアのときは、びっくり(大) |
| 通知(成長) | びっくり |
| ホーム(状況の一言) | 苦手問題が1問以上=hungry、5問以上(`MANY_STARS = 5`)=眠そう。葉が集まっている/全部そろった=コンボ。それ以外は通常 |
| 最初の画面 | 星が0=手を振る絵。1問以上=hungry、5問以上=眠そう(`mood.ts`) |
| 言の葉の森の出題・結果 | 解説の画面は、正解=喜び、不正解=しょんぼり。結果の画面は、7問以上正解=喜び、4〜6問=通常、3問以下=しょんぼり |

ホームで使う表情は、**ポーズが変わらないもの**(通常・コンボ・hungry・眠そう)だけ。びっくり・喜び・もぐもぐ・しょんぼりは、手のポーズや耳の形が変わり、成長アクセサリーが体からずれるため、ホームでは使わない(`homeLines.ts` のコメント)。

### ホームの一言

ホーム(タイトル画面)のコトの吹き出し(`src/data/homeLines.ts`)。

- **状況の一言**: ホームを開いたとき、次の順に判定し、最初に当てはまる1つを出す。

| 順 | 条件 | 一言(要約) |
|---|---|---|
| 1 | 苦手問題(星)が1問以上(5問以上は眠そう) | 苦手な問題が残っている。いっしょにやっつけよう |
| 2 | 序章が未クリア | まずは「はじめる」から |
| 3 | 言の葉の森が解放済みで、葉が0枚 | 言の葉の森にも行ってみない?ユライが待っている |
| 4 | 葉が1枚以上80枚未満 | 葉っぱが、あとN枚でぜんぶそろう |
| 5 | 葉が80枚 | 葉っぱがぜんぶそろった |
| 6 | それ以外 | 今日は、どのことばを集める? |

- **タップの一言**: コトをタップするたびに、8つの一言から別のものに替わる(直前と同じものは連続で出さない)。表情付き: 「ん?呼んだ?」「えへへ、くすぐったいよ!」「今日も、ことばをいっぱい食べようね」「ふんふん♪ ことばって、おいしいよね」「わたしのこの葉っぱ、コトノ葉っていうんだよ」「いっしょにがんばろうね!」「ちょっと休憩する?」「文法って、パズルみたいで楽しいよね」。1つ40字以内、絵文字なし(`homeLines.ts` のコメント)。

## 7.3 ことだまの書(図鑑)の構成

ホームから開く。タブで分ける(`src/features/zukan/zukanTabs.ts`)。開いたときは「せいとうりつ」。選んだタブは、画面を離れるまで覚えている(端末には保存しない)。初回だけ、使い方のカードを出す(設定の「操作の説明をもう一度見る」でもう一度出せる)。

| タブのid | 正式名 | 表示ラベル | 中身 | 出る条件 | 詳細 |
|---|---|---|---|---|---|
| `accuracy` | せいとうりつ | せいとう | 単元ごとの正答率、「にがて」、苦手問題の数 | いつも | 4章 |
| `pages` | ぶんぽうの ずかん | ぶんぽう | 文法のことばのまとめ | ページがあるとき(いつも) | 7.5 |
| `nakama` | なかまの ずかん | なかま | 出会った仲間の立ち絵とメモ | いつも(コトは最初から) | 7.4 |
| `kotonoha` | ことわざ・故事成語ずかん | ことのは | 言の葉の森で集めた葉の一覧 | 序章をクリアしたとき | 8章 |
| `memories` | おもいで | おもいで | 称号、エンディングの見返し、見終わったストーリー | いつも | 6・9章 |

- 表示ラベルは、ふりがななしで4文字まで(タブが5つのとき1行に収めるため)。キー操作: 左右の矢印、Home、End。
- 言の葉の森から開いたときは、「もどる」が言の葉の森へ戻る。

## 7.4 なかまの ずかん

データ: `src/data/zukanCharacters.ts`(10枠・12版)。画面: `src/features/zukan/NakamaTab.tsx`。

### 枠と版

1つの枠(人物)に、見た目と文章が変わる「版」が1〜2つある。

| 枠 | 版 | 見出し | 解放の条件 |
|---|---|---|---|
| コト | before | コト | 最初から |
| | after | コレット(もとの名は コト) | ラスボス撃破後の場面(`ohzaNoMa-lastboss-clear`)を見た |
| メイ | — | メイ | `kotobaNoIchiba-subboss-clear` を見た |
| レル | — | レル | `sugatakaeNoKajiba-subboss-clear` |
| オンヴィン | — | オンヴィン | `namerakaNoTaki-subboss-clear` |
| ジョゼット | — | ジョゼット | `tsunagiNoHashi-subboss-clear` |
| ネジラルド | — | ネジラルド | `kizunaNoMa-subboss-clear` |
| サイラス | — | サイラス | `mikakeNoMa-subboss-clear` |
| ニジュヴェール | — | ニジュヴェール | `ohzaNoMa-subboss-clear` |
| 王様 | before | 王様(名前は不明) | 真相(`ohzaNoMa-truth`)を見た |
| | after | ヴェルバルト(もとは 王様) | `ohzaNoMa-lastboss-clear` |
| ユライ | — | ユライ | 言の葉の森に、初めて入場した |

- 条件を満たした**最後の版**を出す。
- 解放されるまでの枠は、黒い影と「？？？」。影の絵は、小ボスは浄化後の立ち絵、ユライは立ち絵(コトの枠は最初から解放されているので、影はない)。
- **王様の枠だけは、解放されるまで、枠ごと出さない**(「？？？」も出さず、総数にも数えない)。したがって、総数は王様の枠が出るまで**9**、出たら**10**。
- 一覧の上に、出会った数「N / 総数」を出す。
- 解放の判定は、見たストーリーの記録(`storyStore`)と、言の葉の森への入場(`kotonohaStore`)。スキップした場面も「見た」に数える。
- 全解放(隠しデバッグ機能)がオンのときは、表示の判定が変わる(存在のみ)。

### 詳細(カードをタップ)

立ち絵(小ボスは、「浄化後/浄化前」の切り替え)、見出し(名前と注記)、名前の由来、役職・持ち場、ひとこと(吹き出し)、メモ(コトまたはコレットが語る。3〜4段落)、ことばの ひとくち(文法のミニ解説。**ある人物とない人物がある**: コトの「前」の版・小ボス7人・ユライにはあり、コレット、王様の両版にはない)。閉じる: 「とじる」、背景のタップ、Escキー。開いている間は背景のスクロールを止める。ふりがなは、文法用語と難読語に付く(`nakamaRuby`)。

### メモの内容(要約)

- **小ボス7人**: コトが語る。名前の由来、乱れ方(言い間違いの例)、浄化後の様子。ことばの ひとくちで、文法の説明をする(例: メイ=名詞と動詞の区別、レル=ら抜き言葉、オンヴィン=音便、ジョゼット=助詞の脱落、ネジラルド=ねじれ文、サイラス=さ入れ言葉、ニジュヴェール=二重敬語)。
- **コト**: 頭の葉っぱ(「コトノ葉」)、文節の見分け方の例、主人公が話さないこと、アクセサリーが増えること。
- **コレット**: 本当の名前、主人公の態度が変わらなかったこと。
- **王様(前)**: 紫の靄の王。コトが言い返したこと。
- **ヴェルバルト**: 化け狸の姿を宿す御守りの話、謝られたこと(コレットが語る)。
- **ユライ**: 言の葉の森の無口な旅人。ことわざと故事成語に詳しい。
