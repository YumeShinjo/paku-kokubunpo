# 8. 言の葉の森

ことわざ・故事成語のミニゲーム「言の葉の森」を定める。本編(ステージ、ボス、ストーリー)とは別枠のあそびで、進み具合も別に持つ。ユライとコトの人物像は7章、称号は9章、保存キーは10章、BGMは12章。

| 項目 | 内容 | 根拠 |
|---|---|---|

| 問題数 | **80**(ことわざ50+故事成語30)。難易度の内訳: ことわざ 1:20・2:20・3:10、故事成語 1:12・2:12・3:6 | 実行して数えた値 |

## 8.3 ラウンドの進み方

1. ホームの入口から言の葉の森の入口の画面へ。
   - 初回(入口の4行をまだ最後まで見ていない、かつ葉の記録もない)は、ユライ→コト→ユライ→コトの4行の会話を、タップで1行ずつ進める(「つぎへ」「スキップ」)。最後まで進めるか、スキップすると、既読になる。途中で抜けたときは、次も初回の4行から出る。
   - 2回目以降は、3つの台詞(`entry_repeat_a`〜`c`)から、ランダムに1つ。直前に出したものは避ける。
2. **範囲を選ぶ**: 「すべて」「ことわざ」「故事成語」(それぞれ「集めた数 / 全部」を表示)。選ぶと、その範囲のユライの一言に替わる(ラウンドはまだ始まらない)。「すすむ」でラウンドを始める。
3. **出題**: 問題の文と選択肢3つ。選ぶと、すぐ解説へ。**不正解でも、やり直しはない**。正解を示して進む。
4. **解説**: 「せいかい!」/「ざんねん」。完全な形、選んだ答えと正解(不正解のときは両方、正解のときは1行)、意味、由来(あれば、「もとの話を見る」で開く)。ユライの一言(`yuraiLine`)は、ユライの隣の吹き出しに出る。コトの表情は、正解=喜び、不正解=しょんぼり。「つぎへ」は画面の下に固定。
5. **結果**: 「N / 10」と、得点帯別のユライとコトの台詞。新しい葉があれば、「あたらしい 葉が N枚 あつまったよ」と、その行に添える台詞(`leaf_new`)。「もういちど」(新しいラウンド)/「もどる」。
6. 効果音: 正解・不正解、ラウンドの終わり(ラウンド終了の音。鳴っている間、BGMを下げる)。80枚そろって称号を授与するときは、小ボス撃破の称号音。

### 問題の選び方(`selectRound`)

1. まだ葉を集めていない問題を優先する(ランダムな順)。
2. 足りなければ、集め済みの問題から補う。**前に間違えた問題を先に**、残りはランダムな順。
3. 同じラウンドで同じ問題を重ねて出さない。範囲に10問未満しかなければ、その数で終える。

### 結果の得点帯

| 条件(10問のとき) | 場面 | コトの表情 |
|---|---|---|
| 10/10 | `result_perfect` | 喜び |
| 7〜9 | `result_high` | 喜び |
| 4〜6 | `result_mid` | 通常 |
| 0〜3 | `result_low` | しょんぼり |

(10問未満のときは割合で見る: 満点=perfect、70%以上=high、40%以上=mid、それ未満=low。)

## 8.4 葉(記録)

| 項目 | 内容 |
|---|---|
| 集めた葉 | **初めて正解**した問題の id。一度集めたら、あとで間違えても減らない |
| まちがえた問題 | 間違えた問題の id。**正解すると外れる**。次のラウンドで優先して出す |
| 保存 | 端末のみ。キー `paku-kokubunpo:kotonoha`(10章)。**引き継ぎコードには含まれない**(`src/features/transfer/` に言の葉の森の項目がない)。「データを初期化」で消える |
| ランキング・累計正解数 | 影響しない(送信しない) |
| 入場の記録 | 言の葉の森の画面を開いた(遊べる状態で)ときに記録。図鑑の「ユライ」を解放する条件(7章)。遊んだ記録(葉を集めた・間違えた)があれば、入場済みとして扱う |
| 保存の版 | 版1: 初回の台詞の既読(`seenEntryFirst`)を追加。それ以前の保存データは、入場済みか遊んだ記録があれば、既読として移行する |

## 8.5 ユライとコトの場面台詞

データ: `src/data/yuraiScenes.ts`(15場面)。ユライの台詞はひらがな中心で、語の切れ目に半角スペース。コトの台詞は漢字かな交じり(ふりがなは画面に出すときに付ける)。1行ずつ話者を分けて出す。

| 場面id | いつ | 行数 |
|---|---|---|
| `entry_first` | 初めて入ったとき | 4 |
| `entry_repeat_a`/`b`/`c` | 2回目以降の入口(3つからランダム) | 各2 |
| `round_start_all`/`kotowaza`/`koji` | 入口で範囲を選んだとき | 各2 |
| `result_perfect`/`high`/`mid`/`low` | 結果画面(得点帯別) | 各2 |
| `leaf_new` | 新しい葉を集めたラウンドの結果 | 2 |
| `complete_all` | 80枚ぜんぶ集めた | 3 |
| `complete_kotowaza` | ことわざ50枚を集め終えた | 2 |
| `complete_koji` | 故事成語30枚を集め終えた | 2 |

### コンプリート

- 「**はじめて埋まった瞬間**」だけ、各1回出す(`shownCompletions`)。結果画面の上に重ねて出し、「つぎへ」/「とじる」で閉じる。
- 80枚(all)と、50枚・30枚が**同時に**埋まったときは、`complete_all` だけ。
- すでに埋まっている端末は、更新のあとで遡って出ない。
- **80枚そろった**ときだけ、ユライから称号「言の葉をひろいし者」を授与する(称号は集めた葉から導くので、別には保存しない)。この称号の名前は、データのコメントで「仮の名前」とされている(9章)。

## 8.6 図鑑の「ことわざ・故事成語ずかん」(ことのは)タブ

序章をクリアするまで、タブは出ない(7章)。中身: 集めた数「N / 80」、80枚そろっていれば称号、集めた葉の一覧。「ことわざ(N / 50)」「故事成語(N / 30)」の見出しに分け、集めた葉は完全な形が見出しで、タップすると、読み、意味、由来(あれば)、ユライの一言が開く。まだ集めていない葉は、薄い葉の形と「？」だけ(答えが分かる文字は出さない)。言の葉の森の入口の「ずかんを みる」から開く。そこでの「もどる」は言の葉の森へ戻る。

## 8.7 ホームの一言との関係

ホームのコトの一言(7章)は、序章をクリアして言の葉の森が遊べるとき、葉の数に応じて変わる(0枚=「ユライが待ってるよ」、1〜79枚=「あと N 枚」、80枚=「ぜんぶそろったね」)。`LEAF_TOTAL = 80` は、`homeLines.ts` に直接書いてある数。
