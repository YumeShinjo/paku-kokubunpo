# 6. ストーリー

ゲーム本編の物語(場面の一覧、流れる順序、ネタバレの扱い)を定める。台詞の全文は載せない(場面ごとの要約と、データの場所だけ)。キャラクターの設定と図鑑は7章、称号とエンディングの結果画面は9章、クレジットは14章。

> **この章はネタバレを含む。**

## 6.1 物語の要約

- 舞台は「コトノハ王国」。国のあちこちで「言葉の乱れ」が広がり、看板の文字が消えかけ、人々の話し方が歪んでいる。
- 主人公(プレイヤー)は、記憶のない見習いの「ことだま使い」。台詞を持たない(動作は、ナレーションで描く)。草原で、相棒のコトと出会う。
- 国の各地で、乱れに取り憑かれた宮廷の役職者(小ボス7人)を、問題に答えて「浄化」し、城の最奥の王座の間へ向かう。倒すのではなく「浄化」する。浄化されると、元の話し方に戻る。
- 王座の間で、宰相が、乱れを王座に招き入れた張本人であることを明かす。王座にいたのは、乱れに飲まれた王様だった。
- 王様(ラスボス)を浄化すると、コトは、行方不明だった王女コレットの本来の姿を取り戻し、王様ヴェルバルトは、コレットの父として正気に戻る。
- エンディングで、プレイヤーは2つの選択肢のどちらかを選ぶ(城に戻る/旅を続ける)。選択に応じて、称号が決まる(9章)。
- テーマ(`STORY.md.md`): 言葉の「変化」と「崩壊」は違う。宰相のエピソードで示す。

## 6.4 流れる順序

初めて遊ぶときの順序(`storyFlow.ts`)。**視聴済みの場面は飛ばす**。場面のデータが見つからないときも、その場面は飛ばす。

1. **エリアに入る**(エリア選択でカードを押す): `<エリア>-intro` → ステージ選択。
2. **ボスに挑む**(ステージ選択でボスを選ぶ): 小ボスは `-subboss-intro` →戦闘画面(5章)。ラスボスは `-lastboss-intro` →戦闘画面。再挑戦(「もういちど」)では流れない。
3. **小ボスを倒す**(5章): `-subboss-clear` →(王座の間のみ)`-truth` →(エリアクリアのとき)`-area-clear` → ステージ選択。
4. **ラスボスを倒す**: `ohzaNoMa-lastboss-clear` → `-ending-choice`(選択)→ 選んだ分岐 → `-epilogue` → `-area-clear` → 称号の授与画面(9章)→ クレジット(14章)→ ステージ選択。**ラスボスを倒したとき、エリアクリアかどうかに関わらず、共通の締め(`-area-clear`)を必ず含める**(エンディングの最後を、通常ステージの消化状況に左右させないため)。称号の授与画面とクレジットは、**一度見たあとは繰り返さない**。
5. **序章**: ボスがいないので、全ステージをクリアしたとき(エリアクリア)に `prologue-area-clear`。
6. 「先へすすむ」(5章): `<エリア>-subboss-assist` → 上の3の流れに合流。

エリアクリアの場面(`-area-clear`)は、そのエリアを初めてクリアしたときだけ出る(視聴済みなら、あとでエリアクリアになっても二度は流れない)。王座の間のエリアクリアは、ラスボスの撃破のあとの共通の締めになる。

| 起点 | 流れる場面(順) |
|---|---|
| 序章に入る | `prologue-intro` |
| 序章をクリア | `prologue-area-clear` |
| エリア①〜⑥に入る | `<エリア>-intro` |
| 小ボス①〜⑥に挑む | `-subboss-intro` |
| 小ボス①〜⑥を倒す | `-subboss-clear` → `-area-clear` |
| 王座の間に入る | `ohzaNoMa-intro` |
| 宰相に挑む | `ohzaNoMa-subboss-intro` |
| 宰相を倒す | `ohzaNoMa-subboss-clear` → `ohzaNoMa-truth` |
| 王様に挑む | `ohzaNoMa-lastboss-intro` |
| 王様を倒す | `lastboss-clear` → `ending-choice` → 分岐 → `epilogue` → `area-clear` → 称号 → クレジット |

## 6.5 再生の仕組み(`StoryScreen`)

| 項目 | 内容 |
|---|---|
| 進め方 | 画面のどこをタップしても次の台詞へ(テキストボックスも含む)。右下に「▼ タップ」(最後の台詞は「▼ タップして とじる」) |

## 6.7 見返し(ことだまの書の「おもいで」)

- **ストーリー**: 見終わった場面を、エリアごとにまとめて、ボタンで再生できる。再生が終わると、ことだまの書の「おもいで」タブへ戻る。「見たストーリーを、もう一度見られるよ。(N / 27)」と数を出す。
- 見返せる場面(合計**27**): 各エリアの `intro`(8)、`subboss-clear`(7)、`area-clear`(8)、そして王座の間の `truth`、`lastboss-intro`、`lastboss-clear`、`epilogue`(4)。表示名は「はじまり」「小ボスを浄化したあと」「真相」「最後の戦いの前」「ラスボスを浄化したあと」「宰相のひとこと」「エリアクリア」。
- **見返せない場面**: `subboss-intro`(全7)、助太刀(全7)、選択肢のある `ending-choice` と、その分岐先(2つ)。
- **エンディングの見返し**: 「エンディングを もういちど 見る」ボタン(エンディングの分岐まで進めば出る)。ラスボスの撃破後の会話から、`ending-choice`(**もう一度選べる**。選び直すと称号も変わる)→ 後日談 → 共通の締め → 称号の授与画面、の順で再生して、戻る。クレジットは挟まない。選択は保存し直される。

## 6.8 他の物語的な内容
