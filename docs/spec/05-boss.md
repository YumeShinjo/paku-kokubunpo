# 5. ボス戦のルール

小ボス(7人)とラスボス(1人)の戦いのルールを定める。ボスのいるステージの位置づけ・解放条件・出題プールは3章、問題そのものの出し方は4章、戦いの前後の会話は6章。

- 序章(ことばの分かれ道)にボスはいない(3章)。
- 出題数・HPは、データから実行して確かめた値。出題数は、プールの大きさ(30〜392)が出題数の上限(20・24)を上回るため、すべて上限どおり。
- 画面の表記は、小ボスが「小ボス: 役職・名前」、ラスボスが「ラスボス: 王様」(`stageTitleText`、`bossLabel`)。ステージ選択で、ラスボスの名前と立ち絵を「？？？」に伏せる条件は3章。**戦闘画面では、名前を伏せる処理はない**。ステージ選択のボタンは、伏せているかどうかに関係なく、解放条件(宰相の撃破)だけで押せる(`StageSelectScreen.tsx`)。そのため、ラスボスを伏せたまま(会話を見終える前に)挑戦できる状況が実際に起こるかは、**未確認**。
- ボスの立ち絵(`BossPortrait`): 小ボスは、エリアごとの1枚絵 `boss/subboss-<エリアid>`。ラスボスは、取り憑かれた姿 `boss/lastboss-possessed`。**戦闘中の立ち絵は、その小ボスを倒したあとでも、取り憑かれた姿のまま**(浄化後の姿は、会話の画面で使う)。素材がなければ、何も出さない(13章)。
- 戦闘中の背景: 上半分に、エリアの背景を大きく出す。そのエリアの関門(小ボス。王座の間だけラスボス)を撃破していれば通常の姿、していなければ荒れた姿。したがって、**王座の間の宰相(小ボス)との戦いは、ラスボスを倒すまで荒れた背景**(`areaPurifyGateStageId`)。

## 5.2 戦いの規則

### HPとライフ

| 項目 | 規則 | 値・根拠 |
|---|---|---|
| ボスのHP | 出題数 N に対し、`max(1, min(ceil(N × 0.6), N − 1))` | `BOSS_CLEAR_RATIO = 0.6`。N=20で12、N=24で15(`bossHpMax`) |
| HPの減り方 | **正解1問につき1**減る。不正解では減らない | `QuizPlayer.tsx`(`handleAnswer`) |
| プレイヤーのライフ | 最大は、基本**5**。不正解1問につき1減る。正解では減らない | `BOSS_LIVES = 5` |
| 勝ち | HPが0になる | — |
| 負け(その1) | ライフが0になる | 画面は「ライフが なくなっちゃった…」 |
| 負け(その2) | 出題を解ききっても、HPが残る | 画面は「もう少し!」(5.5の注) |
| 判定の時点 | 解答のあとの「つぎへ」を押した時点で判定する。HPが0なら勝ち。HPが残りライフが0なら、ライフ切れの負け。どちらでもなく最後の問題なら、「もう少し」 | `QuizPlayer.tsx`(`handleNext`) |

- 勝ちのとき、HPが0になった問題で戦いは終わる(残りの出題は出さない)。
- 解答の演出: 正解=HPゲージが光る(`hp-flash`)。不正解=ボスが横にかわす(`boss-dodge`)。ボスがプレイヤーを攻撃する演出はない。OSの「動きを減らす」設定では、アニメーションを止める。
- ライフはハートで表示する。減った分は、輪郭だけのハートになる。不正解のポップアップに「ライフが 1 へったよ(のこり N)」、0のとき「ライフが なくなっちゃった…」が出る。
- 判定・星・正答率・累計正解数・コンボは、通常ステージと同じように更新する(4章)。HPだけ、ボス戦に固有。
- 正解・不正解の一言は、ボス戦専用の文言を使う(命中=「ヒット！」「きまった！」「いい攻撃！」「効いてる！」、はずれ=「はずれた！でも大丈夫」「もう一回！つぎは当てよう！」「攻撃がそれた！」。見出しは、命中も「せいかい！」、はずれも「ざんねん」の固定のラベル)。復習枠はない(4章)。

### 連敗の救済

| 項目 | 規則 | 値・根拠 |
|---|---|---|
| ライフの増加 | **負けるたびに**(ライフ切れ・「もう少し」のどちらでも)、そのボスの**次の挑戦の最大ライフが1増える** | `bossLivesFor(losses) = 5 + min(4, losses)` |
| 上限 | 増えるのは最大4。最大ライフは**9** | `BOSS_LIFE_BONUS_MAX = 4` |
| 記録 | 負けた回数は、ステージごとに端末へ保存する(`bossLosses`)。そのボスに**勝つ(自力のクリア、または「先へすすむ」)と消える**。「やめる」では増えない | `progressStore.ts`、`StageScreen.tsx` |
| ライフの表示 | 戦闘の冒頭の窓に、ライフの数を書く(「ライフは5つ」など)。ライフが増えているときは、「ライフが 1 ふえたよ!(ぜんぶで N つ)」(負けた直後の再挑戦で、負けた回数が4以下のとき)、または「ライフが N ふえているよ!(ぜんぶで M つ)」 | `StageScreen.tsx`、`stageIntro.ts` |
| 対象 | 小ボス・ラスボスの両方 | — |

最大ライフの推移(負けた回数 → 最大ライフ): 0→5、1→6、2→7、3→8、4以上→9(実行して確かめた値: 5,6,7,8,9,9,9)。

### 「先へすすむ」(小ボスのみ)

| 項目 | 規則 |
|---|---|
| 出る条件 | **小ボス**で、同じボスに**2回以上**(`ASSIST_AFTER_LOSSES = 2`)負けたあとの、負けの画面。**ラスボスには出ない** |
| 選ぶと | 保存した途中経過を消し、そのステージを「クリア+助けてもらった」として記録する。コトの助太刀の短い会話(`<エリアid>-subboss-assist`。全小ボス共通の形)のあと、通常の撃破後の流れに合流する(6章) |
| 得点・星・正答率 | **足さない**(クリア扱いだけ) |
| 印 | ステージ選択に「たすけてもらった」の印が付く。あとで自力で勝つと、通常のクリアに上書きされ、印が消える |
| エリアクリア | これで、エリアのステージがそろうなら、エリアクリアとして扱う(コトの成長・通知。3章) |
| 負けた回数 | 消える |

### 負けの画面

- 見出し: ライフ切れ=「ライフが なくなっちゃった…」、「もう少し」=「もう少し!」。コトは「しょんぼり」の表情。
- 本文: ライフ切れ=「でも大丈夫!ずかんを見ながら、最初からもう一度挑戦しよう!」。「もう少し」=「あと少しで浄化できたよ。何度でも挑戦できるよ!」。
- 「N / M もん せいかい(ボスのHP のこり H)」を出す。
- ボタン: 「もういちど」(その場で、新しい出題で再挑戦。ライフが増えるので、増えた旨の一言が出る)、「先へすすむ」(条件を満たすときだけ)、「もどる」(ステージ選択へ)。
- 「もういちど」の再挑戦では、冒頭の窓はまた出るが、「○○が あらわれた!」は出ない。

## 5.3 戦いの流れ

1. ステージ選択でボスのステージを選ぶ。初めて挑むとき、先に戦闘前の会話が流れる(6章)。保存した途中経過があれば、続きから始める。
2. 戦闘画面の冒頭に、窓を出す(途中からの再開では出さない)。**小ボスで、画面を開いた最初の挑戦だけ**、窓の先頭に「(名前)が あらわれた!」を出す(「もういちど」・途中からの再開では出さない)。窓の文言は、小ボス=「ことばの力を うばう ボスが 立ちはだかる!ライフは N つ。なくなる前に、正しい答えで 浄化しよう!」、ラスボス=「王にとりついた 黒い力との、さいごの 決戦!ライフは N つ。ことばの力を 信じて、浄化しよう!」(ふりがな付き)。ボタンは「たたかう!」。
3. 出題(4章)。画面の上に、ボスの名前・HPゲージ(`HP 現在 / 最大`)・ライフ・進み具合(`N / 全問題数`)が並ぶ。
4. 解答のたびに、判定のポップアップ(HP・ライフの変化つき)。「つぎへ」で次へ。
5. 勝ち → 達成の効果音(小ボス=`subBossPurify`、ラスボス=`lastBossClear`)と画面「(小ボス/ラスボス)を浄化した!」。正解数、最大コンボ、「つぎへ」。得点は10点×正解数を加える(3章。再クリアのたびに足される)。ランキングと累計正解数の送信を行う(9・10章)。「つぎへ」で撃破後の会話などへ(3・6章)。
6. 負け → 5.2「負けの画面」。負けた回数を1増やし、保存した途中経過を消す。

- 途中でやめる: 「やめる」を押すと、確認のあと、ステージ選択へ戻る。進み具合(解答済みの位置・HP・ライフ・コンボ)は残り、次に同じステージを開くと続きから遊べる(3章)。負けにはならない。
- 戦闘中のBGMは、小ボス用・ラスボス用の曲(12章。`src/features/audio/bgmScene.ts`)。

## 5.4 ボス戦に固有でないもの

次は、通常ステージと同じ規則で動く(4章): 判定、解説のポップアップ、星(苦手問題)の付け外し、コンボ、「にがて克服」の演出、ふりがな、出題の形ごとの操作ガイド。ボス戦では、**復習枠(星の問題を混ぜること)は使わない**。
