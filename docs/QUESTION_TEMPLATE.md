# 問題文の受け渡し用テンプレート

問題数を増やすときに、あなたが用意した問題文を、私が出題データ(`src/data/questions/…`)へ組み込むための書式。
**この書式で書いてもらえれば、そのまま組み込める**(ふりがな・正解位置のばらつき・ステージ分割・図鑑への反映は、私の側で処理する)。

### ステージの大きさについて(確定)
通常ステージは SPEC 3章のとおり**1ステージ8〜10問**のまま。「12〜15問」は、各単元の問題データの総量(プール)の目安で、ステージの出題数とは別の話。

## 2. 書式(出題形式ごと)

共通のルール:
- 単元は、下の「単元ID」から選ぶ(新しい単元にしたいときは、名前だけ書いてもらえれば、私が単元IDを作る)。
- 漢字にふりがなが必要なところは `漢字[ふりがな]` と書く(**文法用語は自動で付く**ので書かなくてよい)。
- 解説は必ず付ける(間違えたときに表示される)。1〜2文で。
- 問題は「画面」単位。同じ単元の中で、答えの位置(選択肢の何番目か)は私がばらつかせるので、**正解を先頭に書いてよい**。

### A. 選択式(選択肢から選ぶ)
```
単元ID:
場面(任意。敬語などの場面説明):
問題文:
選択肢: 正解 / 誤答1 / 誤答2 (2〜4個)
解説:
```

### B. 文中タップ(文の中の文節をタップして答える。絆の間)
```
単元ID:
問題文: 「〇〇」に対応する述語をタップしましょう。
文(文節をスペースで区切る): 弟が 公園で 元気に 遊ぶ。
基準の文節(ヒントとして固定表示): 弟が
正解の文節: 遊ぶ。
解説:
```
基準と正解は、文の中に**ちょうど1つ**ずつ入っていること。

### C. 穴埋め(空欄に入るカードを選ぶ)
```
単元ID:
指示文:
文(空欄を ___ で書く): 書く+た→書___た
カード: 正解 / 誤答1 / 誤答2
解説:
```

### D. 仕分け(語を、正しいカゴに分ける)
```
単元ID:
指示文:
カゴ: 動詞 / 形容詞 / …
項目(1画面に3〜5個くらい):
  - 文または語 → 正解のカゴ → 解説
  - …
```

## 4. 私の側で行うこと(組み込み)
1. 問題データへ追加(問題idは単元ごとに連番で採番)。
2. ふりがなの付け漏れ、選択肢・カードの重複、文中タップの「基準・正解が文中に1つずつ」などを、自動テストで検査する。
3. ステージの分割・小ボスの出題数・ラスボスの出題プールは、問題数の増加に合わせて自動で調整される(コードの変更は不要)。
4. 全問題を通しで解ける自動確認(全問正解のプレイ)を行う。

## 5. 書くときのコツ
- 誤答は「ありがちな間違い」にする(明らかに違うものだけだと、勉強にならない)。
- 同じ単元の中で、問題文の言い回しや例文が似すぎないようにする(出題選定は単元ごとに均等に選ぶので、多様なほうが飽きにくい)。
- 中学校の教科書・入試で使われる言い方(学校文法)に合わせる。
