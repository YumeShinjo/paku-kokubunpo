`scripts/export-questions.ts` が出題データ(`src/data/questions/`)から自動で作る。問題を直したら `npx vite-node scripts/export-questions.ts` で作り直す。

- ふりがなは省き、文字だけを出している。
- 正解は ✅ **太字** で示す。選択肢の並び(A, B, C…)は、データ上の並び。実際の画面では、正解の位置がばらつくように並べ替えて出題される。
- 仕分けの項目の「」は、画面では白いカードになる対象の語(仕分けるのは「」の中の語)。
- 「問題数」は画面の数(仕分けは1画面に複数の語を並べるので、語の数とは別)。
- 全部で **224画面**。

#### 1. `ichiba-pos-batch-01`(仕分け)
- **形式**: 仕分け
- **指示**: 次の文の、白いカードになっている言葉を、正しい品詞のカゴに分けましょう。
- **カゴ**: 動詞 / 形容詞 / 形容動詞 / 名詞 / 副詞 / 連体詞 / 接続詞 / 感動詞 / 助動詞 / 助詞
- **項目と正解**:
  - 彼は毎朝公園を「走る」。 → **動詞**  
    解説: 言い切りの形がウ段の音(る)で終わる自立語で、動作・存在を表す。
  - 机の上に本が「ある」。 → **動詞**  
    解説: 「存在する」という意味を持ち、活用する自立語。
  - 「ある」日、旅人が村を訪れた。 → **連体詞**  
    解説: 体言「日」を修飾するだけの、活用しない自立語。すぐ上の「ある」と形は同じだが働きが違う。
  - この本はとても「面白い」。 → **形容詞**  
    解説: 言い切りの形が「い」で終わる、活用する自立語。
  - 彼女の部屋はいつも「きれいだ」。 → **形容動詞**  
    解説: 言い切りの形が「だ」で終わる、活用する自立語。「きれい」だけでは名詞として使えない。
