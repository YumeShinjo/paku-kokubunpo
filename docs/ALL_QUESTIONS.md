### 品詞分類(単元ID: `hinshi-bunrui`、5問)

#### 1. `ichiba-pos-batch-01`(仕分け)
- **形式**: 仕分け
- **指示**: 次の文の、白いカードになっている言葉を、正しい品詞のカゴに分けましょう。
- **カゴ**: 動詞 / 形容詞 / 形容動詞 / 名詞 / 副詞 / 連体詞 / 接続詞 / 感動詞 / 助動詞 / 助詞
- **項目と正解**:
  - 彼は毎朝公園を「走る」。 → **動詞**  
    解説: 言い切りの形がウ段の音(る)で終わる自立語で、動作・存在を表す。
  - 机の上に本が「ある」。 → **動詞**  
    解説: 「存在する」という意味を持ち、活用する自立語。
  - 「ある」日、旅人が村を訪れた。 → **連体詞**  
    解説: 体言「日」を修飾するだけの、活用しない自立語。動詞の「ある」(存在する)と形は同じだが、働きが違う。
  - この本はとても「面白い」。 → **形容詞**  
    解説: 言い切りの形が「い」で終わる、活用する自立語。
  - 彼女の部屋はいつも「きれいだ」。 → **形容動詞**  
    解説: 言い切りの形が「だ」で終わり、状態・性質を表す、活用する自立語。

#### 2. `ichiba-pos-batch-02`(仕分け)
- **形式**: 仕分け
- **指示**: 次の文の、白いカードになっている言葉を、正しい品詞のカゴに分けましょう。
- **カゴ**: 動詞 / 形容詞 / 形容動詞 / 名詞 / 副詞 / 連体詞 / 接続詞 / 感動詞 / 助動詞 / 助詞
- **項目と正解**:
  - これは私の本「だ」。 → **助動詞**  
    解説: 「本」という名詞(体言)に、断定の意味を付け加える付属語。「本」と「だ」は別の単語。
  - 校庭に「桜」が咲いている。 → **名詞**  
    解説: 活用しない自立語で、主語になることができる(体言)。
  - 彼は「ゆっくり」歩く。 → **副詞**  
    解説: 活用しない自立語で、おもに用言(動詞)を修飾する。
  - 彼女は「静かに」部屋を出た。 → **形容動詞**
