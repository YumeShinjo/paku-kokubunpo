## 1. はじめに

「パクっと国文法」(以下「本アプリ」)は、中学生向けの、日本語の文法を学ぶアプリです。
運営者(以下「わたしたち」)は、利用者(とくに中学生のみなさん)の個人情報とプライバシーを大切にします。
このポリシーでは、本アプリがどんな情報を、なんのために、どのように扱うかを説明します。

**本アプリは、本名・住所・電話番号・メールアドレス・写真・位置情報などを集めません。**

## 2. 集める情報・保存する情報

### (1) 端末の中だけに保存する情報(サーバーには送りません)

遊んだ記録は、お使いの端末(ブラウザの保存領域)の中だけに保存されます。

- 進み具合(クリアしたステージ、得点)、マスコットの成長
- ストーリーの既読・選んだ分岐
- 苦手問題の記録、問題ごとの正答の記録
- 音量などの設定、選んだアイコン
- 操作ガイドを見たかどうか

これらは、わたしたちのサーバーには送られません。ブラウザのデータを消したり、アプリを入れ直したりすると、消えることがあります。
消えないように備えたいときは、「せってい」の「ひきつぎコード」を使ってください(コードは、あなた自身が保管するもので、わたしたちには送られません)。コードは QRコードとしても表示でき、新しい端末では、**カメラ**で読み取れます。カメラの映像は、端末の中で QRコードを読み取るためだけに使い、保存も送信もしません(カメラの許可を求められます。許可しなくても、コードを貼り付ければ使えます)。

### (2) ランキングに参加したときにだけ、サーバーへ送る情報

ランキングは**参加するかどうかを自分で選べます**(参加しなくても、すべての学習機能を使えます)。参加すると、次の情報がサーバーに保存されます。

| 情報 | 内容 |
| --- | --- |
| クラスコード | 先生などが決めた合言葉。同じ合言葉を知っている人どうしだけが、順位表を見られます |
| ニックネーム | 自分で決める呼び名(12文字まで)。**本名を使わないでください** |
| アイコン | 色と図形から選ぶ、かんたんなアイコン |
| 得点 | 累計の得点 |
| 更新時刻 | 得点などを最後に送った時刻 |
| 匿名のID | 端末ごとに自動で作られる、意味のない文字列(メールアドレスやパスワードは使いません) |

順位表には、同じクラスコードの人の**ニックネーム・アイコン・得点・順位**が表示されます。クラスコードを知らない人には、表示されません。

### (3) 通信にともなって自動的に記録される情報

本アプリの配信・ランキングには、Google の Firebase(下の「4. 外部のサービス」)を使っています。
ブラウザがサーバーに接続するときに、IPアドレス・ブラウザの種類・接続日時などが、サービスの運用のために自動的に記録されることがあります。
わたしたちは、これらの情報から、個人を特定することはしません。

## 3. 情報の使いみち

- 学習の記録を保存し、続きから遊べるようにするため
- ランキングを表示するため
- 不正な操作(得点のごまかしなど)や、不適切なニックネームを防ぐため
- アプリの不具合の調査・改善のため

**広告の表示、行動の追跡、外部への販売には使いません。**【現時点では、アクセス解析(アナリティクス)も使っていません。】

## 4. 外部のサービス

本アプリは、次のサービスを使っています。情報は、それぞれのサービスの提供者(Google LLC)のサーバーで保存・処理されます。

- **Firebase Hosting**: アプリの配信
- **Firebase Authentication(匿名認証)**: ランキング用の匿名のID
- **Cloud Firestore**: ランキングのデータの保存

ランキングのデータ(Cloud Firestore)の保存場所は、**日本(東京。asia-northeast1)**です。
アプリの配信(Firebase Hosting)と匿名のID(Firebase Authentication)は、Google が世界各地に置いたサーバーを使うため、日本国外のサーバーで処理されることがあります。
Google の取り扱いは、Google のプライバシーポリシーに従います。

## 5. 情報の共有・提供

法令にもとづく場合など、やむを得ない場合を除き、集めた情報を、本人の同意なく第三者に提供しません。
(上の外部のサービスは、サービスの運用のために情報を扱うもので、わたしたちが情報を渡しているわけではありません。)

## 6. 情報の保存期間と、削除のしかた

- 端末の中の記録は、ブラウザのデータを消すか、「せってい」の「データを初期化する」で消えます。
- ランキングのデータは、ランキングから抜ける、または「データを初期化する」で、順位表から自分のデータが消えます。ネットにつながっていないときに初期化すると、順位表にデータが残ることがあります。その場合は、問い合わせ先に連絡してください(【本人確認の方法を決めて記入】)。
- 【ランキングのデータは、最後の更新から○か月たったら削除する、などの運用があれば記入】

## 8. 安全のための取り組み

- ランキングのデータは、本人の端末だけが、自分の分を書き換えられるようにしています。
- ニックネームには、不適切な言葉を使えないようにする仕組みがあります(完全ではありません。気づいたときは、ご連絡ください)。
- 得点は、増え方に上限を設け、極端な値を受け付けません。
- 通信は、暗号化(HTTPS)されています。
