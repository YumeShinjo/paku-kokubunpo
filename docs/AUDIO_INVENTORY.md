# 効果音・BGMの一覧(2026-10-15)

アプリが鳴らす音の、ファイル名・使う場面・出典の状況・長さ・音量の一覧。
音声ファイルそのものは Git に置いていない(`src/assets/audio/` は `.gitignore` で除外。曲の二次配布の禁止のため)。

- **ファイルの場所は1か所**: `src/assets/audio/bgm/<場面>.mp3` と `src/assets/audio/se/<種類>.mp3`。同じ名前のファイルを置けば、コードを変えずに差し替わる。
  名前の決め方は `src/assets/registry.ts`(効果音は `seAssetName`、BGMは `findBgm`)。効果音の種類は `src/lib/audio.ts` の `SeKind`。
- **音量(LUFS)**: Chromium で MP3 をデコードして、ITU-R BS.1770 の方式(K特性フィルタ・400msのブロック・ゲート)で、全体の統合ラウドネスを測った値。
  ピークは、デコード後の最大の振幅(dBFS)。0.0 に近いほど、割れやすい。4秒に満たない効果音は、ブロックが少なく、参考値。
- **出典の状況**: 「確認済み」は、入手元ページと規約を確認できたもの。「要確認」は、規約の本文または入手元ページが未確認(くわしくは `docs/ASSET_CREDITS.md`)。

## 場面ごとの、音が鳴っているか

| 場面 | 鳴る音 |
| --- | --- |
| 通常ステージの敵を倒す(クリア) | `clear` |
| 小ボス(メイほか)を倒す | 命中ごとに `correct`。HPが0になって、結果画面に切り替わった瞬間に `subBossClear` |
| ボス戦の正解 / 不正解 | `correct` / `incorrect`(通常ステージと同じ音。メッセージだけ「ヒット!」「はずれた!」) |
| ボス戦の撃破 | 小ボスは `subBossClear`、ラスボスは `lastBossClear` |
| ドラッグ問題でカードを置く | マウス: ドロップのあとの click で `tap` が1回鳴る(`App.tsx` の共通のタップ音)。指(タッチ): 鳴らない(`touchend` で click を止めているため)。専用の音はない |
| ドラッグ問題でカードを戻す(別のカゴへ入れ直す) | 置くときと同じ(専用の音はない) |
| タップ選択(カードを押す→カゴのボタンを押す) | それぞれ `tap` |
| 言の葉の森で80/80そろったとき | 専用の音はない。そのラウンドの最後の `roundEnd` と、結果画面のユライ・コトの台詞(`complete_all`)だけ |

## 差し替えやすさ(小ボスを倒したときの音)

- 小ボスを倒したときに鳴るのは、`src/assets/audio/se/subBossClear.mp3`(素材名「衝撃」)。
- 同じ名前のMP3を置けば、コードを変えずに差し替わる。台帳(`docs/ASSET_CREDITS.md`)の「衝撃」の行も書き換えること。
- `subBossClear` は、7エリアの小ボスすべてと、称号の授与の画面(`EndingResultScreen`)で共通。メイだけ別の音にしたいときは、効果音の種類を1つ足す(`SeKind` と `StageScreen` の1か所)。
